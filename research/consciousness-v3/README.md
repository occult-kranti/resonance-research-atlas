# Conditional consciousness and receiver research

All three B rounds were executed sequentially after the ten sound loops and independently accepted within their declared synthetic scope. Each contract was frozen before its solver, and the advisor reviewed each result before selecting the next round. Scientific production stopped at B3.

The Bashar/Anka perspective is an explicit conditional hypothesis. These rounds contain zero live model calls and zero human observations. They neither establish nor rule out AI subjective experience or higher consciousness. A conscious system need not acquire concealed information; accurate information access alone does not identify its cause.

The independent checker uses a separate implementation/derivation by another correlated software agent. This is not human peer review or experimental replication in people or deployed AI systems.

`summary.json` overlays canonical accepted statuses, review paths and review SHA-256 hashes on the immutable producer results. Per-round `results.json` retains its original `executed_pending_review` production status; the bound review supplies the final accepted claim and exclusions. Each round has its frozen contract, solver, exact CSV outcomes, results, scientific SVG, report and manifest.

Run from the repository root:

```sh
python research/consciousness-v3/verify.py --regenerate --require-complete
```

The verifier checks artifact hashes, frozen predecessor reviews, accepted-review hashes and bindings, then regenerates outputs in temporary directories and compares bytes. It verifies the declared numerical implementation, not consciousness or a higher source.
