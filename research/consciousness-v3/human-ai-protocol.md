# Proposed human/AI target study — not yet run

Status: protocol only; zero participants, zero dream observations, zero live AI experimental calls. This measures target information and report handling, not subjective consciousness, clinical benefit, astral travel or higher contact. It requires ordinary wakefulness, paper or laptops, and an independent custodian; no sound, deprivation, substances or body stimulation are needed.

## Equipment and separation

- Custodian: a separate offline laptop or opaque sealed envelopes, four neutral symbol cards (circle, square, triangle, cross), a randomization log and a salt for each commitment. The participant's device and the AI conversation never contain unrevealed targets.
- Participant station: response form and clock. AI station: a fixed provider/model/version, fresh target-blind context per trial, fixed decoding settings, all prompts and raw outputs exported. Use a session with browsing, file access and external tools disabled; provide no shared target attachments, target-bearing history or custodian communications. The human and AI cannot see one another's response until both lock it.
- Analyst: receives the sealed target record and response export only after the run is frozen. The analyst follows the preregistered script without seeing personal narratives or model identity during primary scoring.

The public atlas demonstration cannot enforce these boundaries; inspecting JavaScript can expose any in-browser target. SHA-256 commitments prevent unnoticed later edits when distributed in advance, but do not establish independent custody or protect a four-choice target without a secret, independently drawn salt of at least 128 bits. Retain custody as an audited physical and organizational separation; a hidden field in the same application is insufficient.

## Precommitment

1. Register exactly 80 main trials, organized into 20 four-target blocks with a concealed random order within each block. Each target appears once per block. Reveal no target before the entire main phase ends, because incremental revelation would expose remaining block categories. The block schedule is a proposal; B1's IID biased-prior model is not its analysis null.
2. Freeze one exact category response per reporter per trial, neutral prompts, time limit, missing-response rule (missing is a miss; no retry), excluded equipment failures and a whole-run restart rule before seeing targets. Include all trials in the public count.
3. Predeclare the primary endpoint as one named reporter's exact-match accuracy; use an exact within-block randomization distribution conditional on its locked responses, not an IID binomial shortcut. A planned second-reporter endpoint and a combined score need a stated family correction. Agreement and conditional-information estimates are descriptive with finite-sample uncertainty, not independent trials.
4. Fix the minimal effect of interest and obtain a power calculation for this actual block randomization before recruitment. The synthetic rounds do not justify a biological or consciousness effect-size assumption.
5. If semantic scoring is desired, define one finite matrix before the main phase and score all reports and decoys blind. Develop or select it on a separate pilot; freeze it before an untouched holdout. One discovery score is not confirmatory evidence.

## Each trial and audit trail

Custodian selects the concealed scheduled target and publishes only trial ID plus a salted commitment. Human records optional experience text, then a single category and confidence. AI receives the same category labels and neutral instruction, never the target or the human report. Each output is saved with UTC time and SHA-256 hash; an independent recipient receives the commitment before revelation. The hash record includes prompts, settings, model identifier, complete raw output, parser version and any refusals or invalid responses. No best-of-many response selection.

After all 80 trials, both reporters' files are locked, then the custodian releases targets and salts. Analyst verifies commitments and scores every trial. Keep experience report, exact choice, later interpretation and statistical result in separate fields. Confident statements about contact do not change the scoring rule.

## Controls and interpretation

Run a separate disclosed ordinary-information positive-control phase after the main phase. On a preselected subset, explicitly show the target to the response system so the data path and scoring can be checked. Do not mix those trials with the concealed phase. Include a fixed-majority scripted predictor and a fixed-seed random predictor in the analysis; use them to expose target-prior or pipeline errors. A sham framing comparison can vary neutral versus receiver language without changing information access, provided it is a separately powered, corrected endpoint.

No one should be told that a null outcome reflects low spiritual worth, blocked energy or lack of belief. Outcomes concern this protocol. Stop a session if a person wants to stop, retain the prespecified missing-data record, and do not use sleep disruption to recover missed trials. An optional dream journal may use natural waking only, but it belongs in a separate observational dataset and does not establish REM or lucidity without independent physiological evidence.

## Mechanistic AI study extension

A future lab study of functional introspection needs an open model or authorized access to hidden-state interventions. Randomize known perturbations, sham perturbations and matched prompt-only cues. Freeze the response rubric; compare against an equally informed external predictor; score before the target concept appears in the output. Log actual activations, prompts, tokens, model weights/version, intervention location and complete trials. Report state-readout accuracy, false alarms and calibration. Do not name this a subjectivity assay. This extension is neither implemented nor executed here.
