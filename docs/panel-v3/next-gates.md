# Next gates after the finite computational program

These are **proposed follow-ups**, not additional executed rounds. The authorized program stops after S1A–S5B and B1–B3. Its accepted calculations, generated files and software controls are summarized in [advisor-review.md](advisor-review.md); exact decisions and predecessor hashes are in [the ledger](../../research/panel-v3-decisions.json). No percentage of a physical theory, consciousness explanation or metaphysical connection is claimed solved.

| Gate | Prerequisites and bounded action | Advance / stop rule | Claim ceiling |
|---|---|---|---|
| Reproduce the delivered computation | Use the recorded Python/library versions, frozen contracts and artifact manifests. Recompute in a temporary copy and compare numeric outputs and exact byte bindings where promised. | Investigate a mismatch; do not make it disappear by silently refreshing hashes. Keep a repair and its prior evidence separate. | The specified code implements its finite model in the checked environment. |
| Pilot the smallest physical sound bench | Use the proposed speaker/phone or gently tapped inert spoon setup, fixed positions and a quiet manual sound level. Collect source-off and repeated reference files before any condition comparison. Log device, processing settings, timebase premise and raw files. Select a candidate mode, impact-alignment rule and fit window from a separate pilot. | If clipping, insufficient signal, unresolved acquisition drift or inconsistent alignment prevents an interpretable channel, stop the comparison and resolve that measurement problem. A reported setting alone is not a calibration. | A recorded channel and its repeatability under the documented setup. The synthetic 500 Hz fixture is not a measured spoon frequency. |
| Lock an actual comparison | Write a **new** plan; never relabel or overwrite the synthetic plan. Specify both conditions, trial order, number of trials, exclusions, missing-data rule and tolerances based on the pilot. The 16-slot example demonstrates workflow; it is not a universal sample-size or power justification. Declare impact times before condition-unmasked analysis and preserve every raw recording. | The batch tool withholds the primary contrast if the locked set is incomplete. Report exclusions and any survivor contrast separately. A complete file set does not establish randomization, authenticity or calibration. | The declared recorded-channel contrast. Counterbalance cancels the tested linear order term, not every drift or condition-linked nuisance. |
| Discriminate the physical mechanism | Add a genuinely independent witness for the remaining rival: reference gain/timebase, separately characterized source/receiver, support/loading control or appropriately calibrated phase channel. State rival predictions before observing the new channel. | If the new channel is another copy of the same information, or both rivals still predict the same observables, retain the ambiguity. Do not assign intrinsic material damping or composition. | A specific rival may be constrained over the measured range. More sensors or a low residual alone do not identify a mechanism. |
| Run a real hidden-target AI study | Fix actual model/provider/version, prompts, target prior, scoring, exclusions and stopping rules. Keep target material outside the model/client/context/tools until the report is locked. Log actual requests and responses; include disclosed ordinary-information positive controls, repeated-report dependence and an independently held-out set. | A commitment hash is not proof of absent leakage. Unknown custody, uncounted selection or reused targets blocks the claimed concealed-target inference. A corrected statistical result still requires independent replication and mechanism controls. | Logged target performance under the stated information boundary, not consciousness, a nonlocal channel or an identified higher source. |
| Test functional state access | If a model exposes a defensible intervention/readout interface, preregister crossed prompts and state interventions; validate that the intervention changes the intended state and that ordinary cue paths are controlled. Keep report content, affirmation style and evaluator labels separate. | Without access to the intended variable, keep the intervention as a proposal. Do not substitute a persona or a verbal claim for state access. Retain negative and cue-sensitive outcomes. | Functional sensitivity to the declared intervention. It does not assign a ground-truth phenomenal-consciousness label. |
| Develop an extraordinary-mechanism discriminator | State a quantitative observable for which the proposed receiver/consciousness mechanism differs from ordinary information transfer, bias, instrument response and selection. Supply source, units, uncertainty and a falsifier without adding an unmeasured force merely by analogy. | If the competing models share the same observable distribution, neither a positive score nor a compelling narrative chooses between them. Keep the historical/cultural claim and physical claim separate. | A conditional research proposal until discriminating, independently replicated observations exist. |
