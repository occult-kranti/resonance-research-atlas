## Selected final target

Use four equally likely target categories and fixed n=40 locked responses in a synthetic benchmark. Compute the exact Binomial(40,1/4) PMF, upper tails and smallest hit count passing a predeclared one-sided alpha=0.05 criterion. Report the achieved null rejection probability, since discreteness can make it lower than alpha.

Add a disclosed information-leakage control: with probability lambda the target is known through an ordinary channel, and otherwise it is guessed uniformly. Then p_hit=lambda+(1−lambda)/4. Compute detection probabilities at lambda=0,0.1,0.5 under the same fixed cutoff. This demonstrates that above-chance scoring does not itself identify an extraordinary mechanism.

Finally compute the chance of ever passing the naive nominal tail criterion while looking after every trial up to 40. Use an exact absorbing Bernoulli dynamic program with time-specific binomial tails. Its states retain the number of hits among surviving paths, and paths crossing the boundary are removed and added to cumulative rejection probability. This handles dependent looks directly. The optional-stopping case is a deliberately invalid use of fixed-sample thresholds, not the proposed primary analysis.

Freeze numerical parameters, tolerances and any illustrative Monte Carlo size/seed before execution. No actual participant, physiological record or hidden target has been tested. A static website may provide a synthetic planning demonstration, an ordinary-sleep observation journal and a protocol; it cannot enforce external target custody or independently verify a dream state.
